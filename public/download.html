Install in three steps

  1. Allow installs from this source. On Android 8+, tap Settings → Apps → Special access → Install unknown apps and allow your browser.
  2. Tap the APK. The file you downloaded is pixel-quest-v1.0.0.apk. Chrome may warn you about the file type — tap Open anyway.
  3. Open Pixel Quest. Create your free account, then add your first quest right away.

If something goes wrong

"App not installed"

A previous copy of Pixel Quest (debug build, different signature) is already on the device. Uninstall it first, then retry.

"Unknown source blocked"

Android blocked the install because the browser isn't allowed to install apps. Re-check step 1 above.

"Play Protect warning"

Play Protect scans sideloaded APKs and warns on any app it hasn't seen before. Tap Install anyway — this is the expected path for any direct APK.
